# 용어 주석 표준 정의

블루가 `glossary`에 넣을 때 기준으로 쓰는 정의다. 문맥에 맞게 다듬되 의미를 바꾸지 않는다. `term`은 본문에 쓴 형태와
똑같이 쓴다(예: 본문이 "예심"이면 term도 "예심"). 숫자가 들어간 제도(기간·세율)는 바뀔 수 있으니, 레드가 그날 출처로
다시 확인한 경우에만 숫자를 넣는다. 표시된 기준일이 1년 넘게 지났으면 숫자 대신 일반 설명을 쓴다.

## IPO 절차
| 용어 | 정의 |
|---|---|
| 상장예비심사(예비심사·예심) | 상장하려는 회사가 거래소에 "상장 자격이 되는지" 먼저 심사받는 절차예요. 통과해야 공모를 시작할 수 있어요. |
| 예심 청구 / 예심 승인 | 청구는 심사를 신청한 것, 승인은 통과 결과를 받은 것이에요. 청구만으로는 상장이 정해지지 않아요. |
| 증권신고서 | 공모 전에 금융감독원에 내는 공식 서류예요. 희망 공모가 범위, 공모 주식 수, 몸값 계산 근거, 위험 요소가 처음 공개돼요. |
| 효력 발생 | 증권신고서를 낸 뒤 정해진 기간이 지나 청약을 받을 수 있게 되는 것이에요. 서류를 고치면(정정) 일정이 밀려요. |
| 정정신고서 | 증권신고서 내용을 고쳐 다시 내는 서류예요. 감독 당국의 요구로 내면 공모 일정이 늦춰지는 경우가 많아요. |
| 투자설명서 | 증권신고서 효력이 생긴 뒤 투자자에게 주는 설명서예요. 내용은 증권신고서와 거의 같아요. |
| 수요예측 | 기관투자자에게 "얼마에, 얼마나 사겠다"를 미리 받아 공모가를 정하는 절차예요. |
| 희망 공모가 밴드 | 회사와 주관사가 제시하는 공모가 범위(하단~상단)예요. 수요예측 결과에 따라 밴드 위·아래로 정해질 수도 있어요. |
| 확정 공모가 | 수요예측을 거쳐 최종으로 정해진 1주당 공모 가격이에요. |
| 기관 경쟁률 | 수요예측에서 기관들이 신청한 수량을 배정 물량으로 나눈 값이에요. 높을수록 기관 수요가 강하다는 뜻이에요. |
| 청약 경쟁률 | 일반 투자자 청약 신청 수량을 배정 물량으로 나눈 값이에요. |
| 대표 주관사 | 상장 절차를 이끌고 공모 주식 판매를 책임지는 증권사예요. 함께 맡는 곳은 공동 주관사라고 해요. |
| 상장 철회 | 진행하던 상장 절차를 멈추는 거예요. 수요예측 부진이나 시장 악화 때 종종 일어나요. |
| 코너스톤 투자자 | 공모 전에 일정 물량을 미리 사겠다고 약속하는 대형 기관투자자예요. 대신 받은 주식을 몇 달간 팔 수 없어요. |
| 사전수요예측 | 정식 수요예측 전에 코너스톤 투자자 등의 수요를 먼저 확인하는 절차예요. 공모 일정이 조금 길어질 수 있어요. |
| 코스피(유가증권시장) | 한국거래소의 대형주 중심 주식시장이에요. |
| 프리IPO | 상장 직전 단계에서 받는 투자예요. 상장 기대감이 가격에 반영돼요. |

## 공모 구조와 상장 직후 수급
| 용어 | 정의 |
|---|---|
| 신주 모집 | 회사가 새 주식을 발행해 파는 거예요. 공모 자금이 회사로 들어가요. |
| 구주매출 | 기존 주주가 가진 주식을 공모 때 파는 거예요. 돈이 회사가 아니라 파는 주주에게 가요. |
| 의무보유확약 | 기관투자자가 공모주를 받는 대신 일정 기간(예: 15일~6개월) 팔지 않겠다고 약속하는 거예요. 비율이 높을수록 상장 초기 매도 물량이 줄어요. |
| 보호예수(의무보유) | 규정이나 약정 때문에 상장 후 일정 기간 주식을 팔 수 없게 묶어 두는 거예요. 최대주주, 상장 직전에 주식을 얻은 주주 등이 대상이 될 수 있어요. |
| 유통가능물량 | 상장 직후 바로 시장에서 팔 수 있는 주식 비율이에요. 많을수록 상장 초기 매도 압력이 커질 수 있어요. |
| 오버행 | 언제든 시장에 나올 수 있는 대기 매도 물량이에요. 보호예수가 풀리는 날 주가 부담이 되곤 해요. |
| 상장 첫날 가격제한폭 | 상장 첫날 주가가 움직일 수 있는 범위예요. 2023년 6월부터 공모가의 60%~400%예요(기준일 2023-06-26 제도 변경). |
| 따블 / 따따블 | 상장 첫날 주가가 공모가의 2배 / 4배가 되는 걸 이르는 속어예요. |
| 우리사주 | 직원이 공모 때 우선 배정받는 주식이에요. 받은 뒤 일정 기간 예탁해야 해서 바로 팔 수 없어요. |

## 가치 평가
| 용어 | 정의 |
|---|---|
| 기업가치(밸류에이션) | 회사의 값어치를 평가한 금액, 또는 평가하는 일이에요. 기사에서 말하는 '몸값'이에요. |
| 시가총액 | 주가 × 발행주식 수예요. 회사 주식 전체의 시장 가격이에요. |
| 추정 시가총액(장외가 기준) | 장외 거래 가격에 발행주식 수를 곱해 거꾸로 계산한 값이에요. 거래가 적어 실제 가치와 차이가 클 수 있어요. |
| 프리머니 / 포스트머니 | 투자를 받기 전 / 받은 후의 기업가치예요. 포스트머니 = 프리머니 + 투자금이에요. |
| 비교기업(피어) | 비슷한 사업을 하는 상장사예요. 이들의 주가 수준이 공모가를 정하는 잣대가 돼요. |
| PER | 주가수익비율. 시가총액을 순이익으로 나눈 값으로, 이익의 몇 배에 거래되는지 보여 줘요. |
| PSR | 주가매출비율. 시가총액을 매출로 나눈 값이에요. 이익이 작거나 들쭉날쭉한 성장 기업에 자주 써요. |
| EV/EBITDA | 기업가치(시가총액+순부채)를 상각 전 영업이익으로 나눈 값이에요. 빚까지 고려한 몸값이 현금 창출력의 몇 배인지 봐요. |
| IPO 할인율 | 비교기업으로 계산한 적정 가치에서 신규 상장 위험을 감안해 일부러 깎아 주는 비율이에요. |

## 실적과 회계
| 용어 | 정의 |
|---|---|
| 영업이익 | 매출에서 원가와 판매·관리비를 뺀 이익이에요. 본업으로 번 돈이에요. |
| 당기순이익 / 순손실 | 영업이익에 이자·투자 손익, 세금까지 반영한 최종 이익(손실)이에요. 일회성 비용 때문에 영업이익과 방향이 다를 수 있어요. |
| 연결 재무제표 | 자회사 실적까지 합쳐 한 회사처럼 만든 재무제표예요. 모회사만 따로 본 것은 '별도' 재무제표예요. |
| 거래액(GMV) | 플랫폼에서 거래된 상품 금액의 합이에요. 회사 매출(수수료·직매입 매출 등)과는 달라요. |
| 영업이익률 | 매출 대비 영업이익 비율이에요. 수익성을 보여 줘요. |
| RCPS(상환전환우선주) | 나중에 돈으로 돌려받거나(상환) 보통주로 바꿀(전환) 수 있는 우선주예요. 회계상 부채로 잡히면 장부상 비용이 생겨 순이익이 줄어 보일 수 있어요. |
| 구주 거래 | 회사가 새로 발행한 주식이 아니라 기존 주주끼리 주식을 사고파는 거예요. 거래 가격이 그 시점의 몸값 힌트가 돼요. |
| 감사보고서 | 회계법인이 재무제표를 검사하고 의견을 붙인 보고서예요. 비상장 대기업도 전자공시에 올라와요. |
| 반기 실적 | 1~6월 6개월 실적이에요. |
| DART | 금융감독원 전자공시시스템이에요. 감사보고서·증권신고서를 볼 수 있어요. |
| KIND | 한국거래소 상장공시시스템이에요. 예비심사 결과와 상장 일정이 올라와요. |
| 세무조사 / 추징금 | 국세청이 세금 신고가 맞는지 조사하는 것이에요. 덜 낸 세금이 확인되면 추징금이 나와요. |

## 장외 거래와 임직원 주식
| 용어 | 정의 |
|---|---|
| 장외시장(비상장 주식 플랫폼) | 거래소에 상장되지 않은 주식을 사고파는 곳이에요. 거래가 적어 가격이 들쭉날쭉하고 플랫폼마다 가격이 달라요. |
| K-OTC | 금융투자협회가 운영하는 비상장 주식 장외 거래 시장이에요. |
| 체결가 / 호가 | 체결가는 실제 거래된 가격, 호가는 사겠다·팔겠다고 내놓은 희망 가격이에요. |
| 호가 차이(스프레드) | 사겠다는 가격과 팔겠다는 가격의 차이예요. 클수록 원하는 값에 팔기 어려워요. |
| RSU(양도제한조건부주식) | 근속 기간 같은 조건을 채우면 회사가 주식을 주는 보상 방식이에요. 지급 시점과 매도 제한은 개인 계약에 따라 달라요. |
| 스톡옵션 | 미리 정한 가격에 회사 주식을 살 수 있는 권리예요. |
| 양도소득세 | 주식을 팔아 남긴 차익에 붙는 세금이에요. 비상장 주식은 소액주주라도 과세되는 경우가 많고, 기업 규모·보유 기간·지분율에 따라 세율이 달라요. 구체적 세율은 그해 세법으로 확인해요. |
| 증권거래세 | 주식을 팔 때 거래 금액에 붙는 세금이에요. 비상장 주식은 상장 주식보다 세율이 높은 편이에요. |
