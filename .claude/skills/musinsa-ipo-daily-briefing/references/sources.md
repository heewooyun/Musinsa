## 1. 검색 쿼리 세트

WebSearch에는 세션·하루 단위 호출 한도가 있을 수 있다. 그래서 두 단계로 나눈다. **1단계**는 매일 한 번에 병렬로 보내고,
**2단계**는 1단계 결과를 보고 필요한 묶음만 고른다. 🔥 표시만 `mode: "extended"`(신선도가 중요), 나머지는 `"standard"`.

| ★1 | `무신사 상장` | 🔥 extended |
| ★2 | `무신사 IPO 예비심사` | 🔥 extended |
| ★3 | `무신사 장외가` | 🔥 extended |
| ★4 | `무신사 증권신고서 공모가` | standard |
| ★5 | `무신사 실적 영업이익` | standard |

| ★7 | `무신사 세무조사 공정위` | standard |

## 3. 장외 시세 기록 규칙

원장과 브리핑에 가격을 적을 때는 다음을 함께 적는다. 하나라도 모르면 "불명"이라고 쓴다.

| 항목 | 예 |
|---|---|
| 플랫폼 | Npay 비상장 |
| 가격 종류 | 최근 체결가 / 체결 평균가 / 기준가 / 매수·매도 호가 |
| 가격 | 00,000원 |
| 기준 시각 | 11/5 15:30 KST |
| 변동 | 전일 대비 +1.2% (비교 기준을 같은 종류의 가격으로) |
| 출처 | URL (기사 인용이면 기사 URL과 "기사 인용") |

- 장외 시세는 한 플랫폼·한 기사에서 나오는 게 보통이다. 위 항목을 밝히면 단일 출처로 써도 된다("Npay 비상장 기준 ○원, ○○ 보도").
- 플랫폼마다 가격이 다르면 평균을 내지 말고 각각 보여 주고, 차이를 "플랫폼 간 가격 차"로 설명한다.
- 추정 시가총액 = 가격 × 발행주식수. 주식 수의 출처(감사보고서·보도 기준일, 무상증자·전환 반영 여부)를 같이 적는다.
- 오늘 새 시세를 못 찾으면 가장 최근 확인값과 그 날짜를 쓰고 "오늘 신규 시세 확인 불가"라고 밝힌다.

## 4. 관련성 필터

**채택 조건**: 무신사가 주체 + 아래 주제 키워드 1개 이상 + 수집 창 안(또는 TOP 5를 채울 때 최근 7일 안의 "지난 자료").

- 주제 키워드: 상장, IPO, 공모, 예비심사(예심), 증권신고서, 수요예측, 청약, 주관사, 코스피·유가증권시장, 실적, 매출,
  영업이익·영업손실, 순이익·순손실, 적자·흑자, 이익률, 거래액, 감사보고서, 회계, 재무, 기업가치, 밸류에이션, 시가총액,
  몸값, 장외, 비상장, 시세, 주가, 투자 유치, 시리즈, 프리IPO, 지분, 최대주주, 보호예수·의무보유, RSU·스톡옵션·우리사주,
  세무조사·추징, 공정위·과징금, 구조조정, 인수·M&A, 자회사, 동향, 전망, 분석, 리포트
- 소비자 언급(이것만 있으면 탈락): 할인, 세일, 쿠폰, 특가, 블랙프라이데이·무진장, 신상, 컬렉션, 룩북, 코디, 래플, 발매,
  팝업, 입점, 협업 출시, 이벤트, 증정, 랭킹, 상품 리뷰, 배송·고객 불만
- 날짜: 검색 결과·원문 어디에서도 발행일을 확인할 수 없으면 창 밖으로 본다. 본문에 창 안 날짜를 가리키는 단서("5일 거래소에 따르면")가 있을 때만 예외.

**경계 사례**
- "무신사 스탠다드 해외 1호점 오픈" → 매출 목표·투자 규모·실적 영향이 함께 나오면 '사업'으로 채택, 오픈 소식만이면 탈락.
- "무신사 블랙프라이데이 거래액 O천억" → 거래액·실적 함의가 핵심이면 채택(실적 지표), 할인 행사 안내면 탈락.
- 경쟁사·비교기업 기사 → 무신사 밸류에이션·IPO와의 연결이 기사 안에 있으면 '업계'로 채택, 아니면 배경.
- 무신사가 한 줄 언급된 업계 일반 기사 → 배경(본문 근거로만, TOP 5에는 다른 자료가 모자랄 때만).

## 5. 자료 TOP 5 순위 매기기

채택 자료마다 점수를 매겨 **합계가 높은 순**으로 고른다. 동점이면 중요도 → 등급 → 최신 순.

| 축 | 점수 |
|---|---|
| 중요도 (0~5) | IPO 일정·공모 구조 직접 5 · 실적·기업가치·지분 4 · 세무·규제·지배구조 4 · 의미 있는 시세 변동(±3% 이상, 신고가·신저가) 4 · 그 밖의 시세 3 · 사업 전략·성장 동력 3 · 업계·비교기업·IPO 시장 2 · 커뮤니티 심리 1 |
| 관련도 (0~3) | 무신사가 주체 3 · 주요 언급 2 · 부수 언급 1 |
| 흥미도 (0~2) | 새 사실·수치·단독 2 · 새로운 관점 1 · 재탕 0 |
| 신뢰 보정 | T1 +1 · T4 −1 |

- 다양성: 같은 사건은 대표 1건만(받아쓰기 기사는 "외 N곳 보도"로 요약에 언급). 커뮤니티 자료는 최대 1건.
- `archive/`에서 이미 소개한 URL은 큰 후속 보도가 아니면 다시 싣지 않는다.
- 카테고리(`category`): IPO · 공시 · 실적 · 시세 · 기업가치 · 지배구조 · 세무·규제 · 사업 · 업계 · 시장 · 커뮤니티.

## 6. 원장 형식 (`out/ledger.json`)

```json
{
  "window": {"since_kst": "2026-11-05 06:10", "until_kst": "2026-11-06 06:10"},
  "searches": {"tier1": 8, "tier2": 6, "failed": 0, "complete": true},
  "items": [
    {
      "id": "S1",
      "title": "기사 원제",
      "outlet": "매체명",
      "published_kst": "2026-11-05 14:20",
      "url": "https://...",
      "tier": "T2",
      "topics": ["IPO", "일정"],
      "key_facts": ["예비심사 결과 이르면 11월 중순(업계 전망)"],
      "in_window": true,
      "verdict": "채택",
      "use": "TOP5 후보",
      "reason": "IPO 일정 신규 보도",
      "score": {"importance": 5, "relevance": 3, "interest": 2, "tier_adj": 0}
    }
  ],
  "references": [
    {"id": "R1", "fact": "2025년 연결 매출 1조 4,679억 원", "from": "context.md §4", "url": "https://newsroom.musinsa.com/newsroom-menu/2026-0331", "tier": "T1"}
  ],
  "rejected_counts": {"창 밖(7일 초과)": 45, "날짜 불명": 12, "무관·소비자 언급": 6, "중복": 11}
}
```

- `items`에는 무신사 + 주제 키워드가 있고 최근 7일 이내이거나 날짜를 모르는 자료만 한 줄씩 적는다. 나머지는 `rejected_counts`에 사유별 개수만 센다.
- `verdict`: **채택**(TOP 5 후보) / **배경**(본문 근거·맥락으로만) / **탈락**. 틀린 보도·루머처럼 팩트체크에서 다룰 자료는 `use: "팩트체크 대상"`으로 표시한다.
- `score`는 채택 자료만 채우고, 나머지는 `null`.
- `references`: `context.md`·`forecasting.md`의 사실을 브리핑에 쓸 때 넣는다. 그 파일에 적힌 출처 URL을 그대로 옮기고, 없으면 `null`과 파일·절을 적는다.
- 탈락 사유를 남겨 두면 다음 날 같은 판단을 반복하지 않는다.
