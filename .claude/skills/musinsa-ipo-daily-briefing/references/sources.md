## 2. 소스 지도와 신뢰 등급

| 등급 | 무엇 | 예 | 쓰는 법 |
|---|---|---|---|
| **T1** 공식 | 공시·거래소·감독기관·회사 공식 발표 | DART(감사보고서, 증권신고서, 투자설명서), KIND·한국거래소(예비심사 결과, 신규상장 안내), 금융위·금감원 발표, 무신사 공식 보도자료·뉴스룸 | 단일 출처로 사실 확정 가능 |
| **T2** 주요 언론·리포트 | 경제지·통신사·IB 전문 매체, 증권사 리포트 | 연합뉴스·연합인포맥스, 한국경제, 매일경제, 서울경제, 머니투데이, 이데일리, 아시아경제, 헤럴드경제, 파이낸셜뉴스, 조선비즈, 뉴스핌, 더벨, 딜사이트, 인베스트조선, 비즈니스포스트 등 | 핵심 수치는 서로 다른 두 곳 일치 시 확정 |
| **T3** 전문·분석 | 업계 전문지, 기업 분석 서비스, 분석 블로그 | 패션 업계지, 스타트업·기업 데이터 서비스, 애널리스트·투자 블로그 | 해석·관점 참고. 수치는 T1/T2로 재확인 |
| **T4** 커뮤니티 | 종목토론방, 비상장 플랫폼 게시판, 커뮤니티 | Npay 비상장·서울거래 비상장 게시판, 38커뮤니케이션 게시판, 블라인드, 카페, 영상 댓글 | 시장 심리 참고만. 사실 근거 불가, 닉네임·개인정보 인용 금지 |

**비상장 시세 소스**(가격 자체는 T2급으로 다루되 기준 시각을 반드시 적는다. 기준일 2026-11-05)

  `https://www.ustockplus.com/stock/musinsa-458860`. 기준가·체결가(체결 평균가)·호가가 따로 있다. 연동 증권사 에스크로로 결제.
- **서울거래 비상장** (`seoulexchange.kr`) — 체결가·호가. 신한·NH 계좌 연동 안전거래.

## 3. 장외 시세 기록 규칙

원장과 브리핑에 가격을 적을 때는 다음을 함께 적는다. 하나라도 모르면 "불명"이라고 쓴다.

| 항목 | 예 |
|---|---|
| 플랫폼 | Npay 비상장 |
| 가격 종류 | 최근 체결가 / 기준가 / 매수·매도 호가 |
| 가격 | 00,000원 |
| 기준 시각 | 11/5 15:30 KST |
| 변동 | 전일 대비 +1.2% (비교 기준을 같은 종류의 가격으로) |
| 출처 | URL (기사 인용이면 기사 URL과 "기사 인용") |

- 플랫폼마다 가격이 다르면 평균을 내지 말고 각각 보여 주고, 차이를 "플랫폼 간 가격 차"로 설명한다.
- 추정 시가총액 = 가격 × 발행주식수. 주식 수의 출처(감사보고서 연도, 액면분할 반영 여부)를 같이 적는다.
- 오늘 새 시세를 못 찾으면 가장 최근 확인값과 그 날짜를 쓰고 "오늘 신규 시세 확인 불가"라고 밝힌다.

## 4. 관련성 필터

**채택 조건**: 무신사가 주체 + 아래 주제 키워드 1개 이상 + 수집 창 안(또는 "지난 자료" 표시).

- 주제 키워드: 상장, IPO, 공모, 예비심사(예심), 증권신고서, 수요예측, 청약, 주관사, 코스피·유가증권시장, 실적, 매출,
  영업이익·영업손실, 순이익·순손실, 적자·흑자, 이익률, 거래액, 감사보고서, 회계, 재무, 기업가치, 밸류에이션, 시가총액,
  몸값, 장외, 비상장, 시세, 주가, 투자 유치, 시리즈, 프리IPO, 지분, 최대주주, 보호예수·의무보유, RSU·스톡옵션·우리사주,
  세무조사·추징, 공정위·과징금, 구조조정, 인수·M&A, 자회사, 동향, 전망, 분석, 리포트
- 소비자 언급(이것만 있으면 탈락): 할인, 세일, 쿠폰, 특가, 블랙프라이데이·무진장, 신상, 컬렉션, 룩북, 코디, 래플, 발매,
  팝업, 입점, 협업 출시, 이벤트, 증정, 랭킹, 상품 리뷰, 배송·고객 불만

**경계 사례**
- "무신사 스탠다드 해외 1호점 오픈" → 매출 목표·투자 규모·실적 영향이 함께 나오면 '사업 동향'으로 채택, 오픈 소식만이면 탈락.
- "무신사 블랙프라이데이 거래액 O천억" → 거래액·실적 함의가 핵심이면 채택(실적 지표), 할인 행사 안내면 탈락.
- 경쟁사·비교기업 기사 → 무신사 밸류에이션·IPO와의 연결이 기사 안에 있거나 블랙이 명확히 설명할 수 있을 때만 '업계'로 채택.
- 무신사가 한 줄 언급된 업계 일반 기사 → 관련도 1점, 다른 자료가 충분하면 제외.

## 5. 자료 TOP 5 순위 매기기

채택 자료마다 점수를 매겨 높은 순으로 고른다.

| 축 | 점수 |
|---|---|
| 중요도 (0~5) | IPO 일정·공모 구조 직접 5 · 실적·기업가치·지분 4 · 지배구조·규제·세무 4 · 시세 3 · 사업 전략·성장 동력 3 · 업계·비교기업·IPO 시장 2 · 커뮤니티 심리 1 |
| 관련도 (0~3) | 무신사가 주체 3 · 주요 언급 2 · 부수 언급 1 |
| 흥미도 (0~2) | 새 사실·수치·단독 2 · 새로운 관점 1 · 재탕 0 |
| 신뢰 보정 | T1 +1 · T4 −1 |

- 동점이면 더 최신, 더 높은 등급 순.
- 다양성: 같은 사건은 대표 1건만(받아쓰기 기사는 "외 N곳 보도"로 요약에 언급). 커뮤니티 자료는 최대 1건.
- `archive/`에서 이미 소개한 URL은 큰 후속 보도가 아니면 다시 싣지 않는다.

## 6. 원장 항목 형식 (`out/ledger.json`)

```json
[
  {
    "id": "S1",
    "title": "기사 원제",
    "outlet": "매체명",
    "published_kst": "2026-11-05 14:20",
    "url": "https://...",
    "tier": "T2",
    "topics": ["IPO", "일정"],
    "key_facts": ["예비심사 청구일 2026-09-07", "기업가치 8조원 거론(업계 추정)"],
    "in_window": true,
    "verdict": "채택",
    "reason": "IPO 일정 신규 보도",
    "score": {"importance": 5, "relevance": 3, "interest": 2, "tier_adj": 0}
  }
]
```
탈락 자료도 `verdict: "탈락"`과 사유(예: "소비자 언급만", "창 밖", "중복: S3와 같은 보도자료")를 남긴다. 다음 날 같은 판단을 반복하지 않게 해 준다.
