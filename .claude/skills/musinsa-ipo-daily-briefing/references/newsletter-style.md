# 블루의 스타일 가이드 — 무신사 장외일보

데일리 경제 뉴스레터처럼 "핵심 먼저, 쉬운 말로, 친구에게 설명하듯" 쓴다. 특정 뉴스레터의 이름·마스코트·고유 표현을
흉내 내지 않고, 분위기만 참고한다.

## 1. 독자와 목표
- 독자: 무신사 비상장 주주 한 명. 금융 비전문가일 수 있다. 출근길 휴대폰으로 3분 안에 읽는다.
- 목표: 다 읽고 나면 "어제 무슨 일이 있었고, 상장 시계가 어디쯤이며, 오늘 뭘 지켜보면 되는지"를 말할 수 있어야 한다.

## 2. 문체
- 해요체. "~했어요", "~거든요", "~일 수 있어요". 반말·과한 유행어·밈은 쓰지 않는다.
- 두괄식. 각 단락 첫 문장이 결론이다.
- 한 문장 40자 안팎, 길어도 60자. 쉼표로 이어 붙이지 말고 끊는다.
- 숫자는 단위와 기준을 함께: "상반기 영업이익 523억 원(연결, 전년 대비 -11%)". 기준일이 중요한 숫자는 날짜를 붙인다.
- 예측은 문장 끝에 "(예측)"을 붙이거나 "~로 보여요(예측)"처럼 쓴다. "확정", "무조건", "반드시 오른다" 금지.
- 공포·환호를 부추기지 않는다. "폭락", "대박", "놓치면 후회" 같은 표현 금지.
- 강조(`**굵게**`)는 단락당 1~2곳, 오늘 가장 중요한 말에만.
- 이모지는 섹션 제목에만(템플릿이 처리). 본문에는 넣지 않는다.

## 3. 구성 요소별 지침 (`briefing.json` 필드)

| 필드 | 지침 |
|---|---|
| `headline` | 오늘 가장 중요한 변화를 45자 이내 한 줄로. 질문형·말줄임은 가능, 과장 금지. 예: "예비심사 두 달째, 결과 발표 임박 신호" |
| `preheader` | 받은편지함 미리보기 90자 이내. 헤드라인을 반복하지 말고 보충 |
| `greeting` | 1~2문장. 오늘 분위기를 한 줄로 |
| `snapshot` | 2~4칸. 장외 시세(플랫폼별), 추정 시가총액(예측 표시), IPO 진행 단계(며칠째), 다음 이벤트. 칸마다 출처 또는 예측 표시 |
| `opinion.body` | **공백 포함 300~500자.** 아래 6단 구성 |
| `predictions` | 상장 예상 시점 / 예상 공모가 / 상장 초기 주가 세 줄. 값은 범위나 시나리오로, `confidence`(상·중·하), `basis`(근거 한 줄) |
| `qa` | 0~2개. 화이트의 질문 중 독자에게 가장 쓸모 있는 것. 답은 3문장 이내 |
| `articles` | 정확히 5개(부족하면 `shortfall_reason`). 아래 기사 지침 |
| `fact_check` | 0~3개. 독자가 알아야 할 정정·루머 반박·주의. `kind`: 수정/주의/확인 |
| `glossary` | 3~7개 권장. 본문에 쓴 형태 그대로 `term`, 정의는 `glossary.md` 표준 정의를 다듬어 사용 |
| `method_note` | "수집 범위 11/5 06:10~11/6 06:10 (KST) · 검토 41건 → 기준 통과 9건 → 5건 선정" 형식 |

### 전문가 의견 6단 구성 (300~500자)
1. **오늘 무엇이 바뀌었나** — 한두 문장
2. **시세 추이** — 플랫폼별 가격 방향과 그 해석
3. **상장 예상 시점** — 단계와 일정 계산 결과(예측)
4. **공모가·상장 초기 가격** — 범위·조건(예측)
5. **실적 전망** — 최근 공시 숫자와 방향
6. **오늘의 체크포인트** — 무엇을 지켜보면 되는지 한 문장

새 소식이 한 꼭지에 몰린 날은 그 꼭지를 늘리고 나머지는 한 문장씩 줄인다. 다만 시세·상장 시점·실적 전망은
한 문장씩이라도 반드시 들어간다.

### 기사 지침
- `title`: 원제 그대로. 우리 말로 바꾸지 않는다.
- `summary`: 자기 말로 2문장, 100자 안팎. 기사 문장을 그대로 옮기지 않는다. 창 밖 자료면 앞에 "(지난 자료)".
- `why`: "왜 중요해?" 한 문장. 독자의 주식(시세·상장 시점·공모가·실적) 중 무엇과 연결되는지 말한다.
- `category`: IPO · 공시 · 실적 · 시세 · 기업가치 · 지배구조 · 사업 · 업계 · 시장 · 커뮤니티 중 하나.
- `tier`: T1~T4. 커뮤니티 자료는 summary에 "확인된 사실은 아니에요" 류의 단서를 단다.

## 4. 용어 주석 규칙
- 비금융인이 멈칫할 단어는 모두 넣는다: 예비심사, 증권신고서, 수요예측, 공모가 밴드, 구주매출, 오버행, 보호예수,
  유통가능물량, 밸류에이션, PER, 연결 재무제표 등. "상장", "매출"처럼 누구나 아는 말은 넣지 않는다.
- `term`은 본문에 쓴 형태와 글자까지 같아야 렌더러가 주석 번호를 단다(띄어쓰기 포함).
- 정의는 1~2문장, 80자 안팎. 비유 하나는 좋다. 정확성이 우선 — `glossary.md`의 표준 정의를 기준으로 쓴다.

## 5. 좋은 예와 나쁜 예

**나쁜 의견 (고쳐야 할 점이 많은 예)**
> 무신사가 드디어 상장을 앞두고 있습니다!! 기업가치 10조는 확실해 보이며 공모가는 장외가보다 훨씬 높게 정해질 것입니다.
> 지금이 매수 적기입니다. 수요예측과 의무보유확약, 구주매출 등도 중요한 변수입니다.

- 과장("드디어", "!!"), 예측을 사실처럼("확실", "정해질 것"), 투자 권유("매수 적기"), 근거 없음, 용어 설명 없음,
  시세·일정·실적 정보가 없다.

**좋은 의견 (형식 참고용 — 사실은 매일 새로 확인할 것)**
> 어제는 새 공시 없이 **예비심사 결과 대기**가 이어졌어요. 장외 시세는 플랫폼마다 엇갈렸지만 1주일 기준으론 보합이에요.
> 예비심사 승인 뒤 증권신고서 제출까지 보통 1~2개월 걸리는 점을 감안하면 상장은 내년 1분기가 기본 시나리오예요(예측).
> 공모가는 거론되는 기업가치에 통상적인 IPO 할인율을 적용하면 현재 장외가보다 낮게 정해질 가능성도 열어 둬야 해요(예측).
> 실적은 상반기 영업이익이 줄어 몸값 논리의 약한 고리예요. 오늘은 거래소의 예비심사 결과 발표 여부를 지켜보세요.

- 무엇이 바뀌었나 → 시세 → 시점(예측) → 공모가(예측) → 실적 → 체크포인트 순서, 예측 표시, 권유 없음, 숫자의 기준이 있다.
